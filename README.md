Python Programming Assignment 
Overview : Conditionals, Loops and Lists 

1. grade_checker.py   
Using if-elif-else statement to convert numeric grade to letter based grade and include messages 
Example output: 
  Enter your grade: 66 
  Your grade is: D 
  Keep trying! You can do better next time. 
  Enter your grade: 80 
  Your grade is: B 
  Congratulations! You passed! 

2. even_sum.py 
Use FOR and WHILE loop to get the sum of even numbers from 1 to 50 and compare. 
Example output: 
  The sum of even numbers from 1 to 50 is 650. 
  The sum of even numbers from 1 to 50 is 650 
Both for loop and while loop created the same result but for loop is clearer and easier  
to understand because it automatically iterates through the numbers in the specified range unlike  
in the while loop were you have to manually initialize and increase the counter.

4. bubble_sort_demo.py 
Implement a simple bubble sort, print the list at each pass of the outer loop to show the progress of the loop. 
Example output: 
  original list: [64, 25, 12, 22, 11] 
  After pass 1 : [25, 12, 22, 11, 64] 
  After pass 2 : [12, 22, 11, 25, 64] 
  After pass 3 : [12, 11, 22, 25, 64] 
  After pass 4 : [11, 12, 22, 25, 64] 
  Final sorted list: [11, 12, 22, 25, 64]
